## 1. What This App Does

**PDF Chat** is a web application that lets you:

- Upload PDF files.
- Ask questions about those PDFs in a chat interface.
- Get answers generated by AI (OpenAI's models), grounded in the actual text of your
  documents, with citations showing exactly which page the answer came from.

It runs entirely on your own computer (your "localhost") and only talks to OpenAI's
servers to generate answers - your PDFs are stored locally.

## 2. Installing Python

Python is the programming language this app is written in. You need it installed before
anything else will work.

### Windows

1. Go to **https://www.python.org/downloads/** in your web browser.
2. Click the yellow **"Download Python 3.x.x"** button (get the latest 3.12 or newer).
3. Open the downloaded installer file.
4. **IMPORTANT:** On the first install screen, check the box at the bottom that says
   **"Add python.exe to PATH"** before clicking "Install Now". This step is the #1
   cause of beginner problems if skipped.
5. Wait for installation to finish, then click "Close".
6. Verify it worked: press `Windows key`, type `cmd`, press Enter to open Command
   Prompt, then type:
   ```
   python --version
   ```
   You should see something like `Python 3.12.4`. If you see an error, restart your
   computer and try again.

### macOS

1. Go to **https://www.python.org/downloads/** and download the macOS installer (latest
   3.12 or newer).
2. Open the downloaded `.pkg` file and follow the installer prompts (Continue -> Continue
   -> Agree -> Install).
3. Enter your Mac password if asked.
4. Verify it worked: open **Terminal** (press `Cmd + Space`, type "Terminal", press
   Enter), then type:
   ```
   python3 --version
   ```
   You should see something like `Python 3.12.4`.

## 7. Creating a Virtual Environment

A **virtual environment** is an isolated Python "sandbox" for this project, so its
dependencies don't clash with other Python projects on your computer. Always use one.

In the VS Code terminal (make sure you're inside the project folder), run:

**Windows:**

```
python -m venv venv
```

**macOS:**

```
python3 -m venv venv
```

This creates a new folder called `venv` inside your project. That folder is already
excluded from Git via `.gitignore`, so you don't need to worry about it.

---

## 8. Activating the Virtual Environment

Activating "switches on" the sandbox so any Python commands you run use it.

**Windows (Command Prompt):**

```
venv\Scripts\activate
```

**Windows (PowerShell)** - if the above gives a permissions error, try:

```
venv\Scripts\Activate.ps1
```

If PowerShell blocks this with a script-execution error, run this once, then try again:

```
Set-ExecutionPolicy -Scope CurrentUser RemoteSigned
```

**macOS (Terminal):**

```
source venv/bin/activate
```

✅ **You'll know it worked** when you see `(venv)` appear at the start of your terminal
prompt line, like: `(venv) C:\Users\You\pdf-chat>`

> You need to activate the virtual environment **every time** you open a new terminal to
> work on this project (the startup scripts in Section 12 do this for you automatically).

## 10. Creating Your `.env` File

The project needs a private configuration file called `.env` (note the leading dot) to
store settings like your API key. It is **not** included in the project by default (and
should never be shared or uploaded anywhere) - instead, a template called `.env.example`
is provided.

1. In the VS Code file tree, find `.env.example`.
2. Make a copy of it and rename the copy to exactly `.env`.
   - **Windows terminal command:** `copy .env.example .env`
   - **macOS terminal command:** `cp .env.example .env`
3. Open the new `.env` file by clicking it in VS Code.
4. You'll fill in `OPENAI_API_KEY` in the next step. Everything else can be left at its
   default value for now.

---

## 11. Getting an OpenAI API Key

This app uses OpenAI's models to generate answers, which requires an API key (a private
password that identifies your account for billing/usage).

1. Go to **https://platform.openai.com/api-keys** and sign in (or create a free
   account).
2. Click **"Create new secret key"**.
3. Give it a name (e.g. "pdf-chat-local") and click **Create**.
4. **Copy the key immediately** - it starts with `sk-` and OpenAI will only show it to
   you once.
5. Open your `.env` file in VS Code and replace the placeholder line:
   ```
   OPENAI_API_KEY=sk-your-openai-api-key-here
   ```
   with your real key, e.g.:
   ```
   OPENAI_API_KEY=sk-abc123...yourrealkey
   ```
6. Save the file (`Ctrl+S` / `Cmd+S`).

> 💰 **Note:** OpenAI usage is billed per request (usually fractions of a cent per
> question for small documents). Check https://platform.openai.com/usage to monitor
> spend, and consider setting a usage limit in your OpenAI account settings.

## 12. Running the Application

You have two options: the easy double-click scripts, or the manual terminal command.

### Option A - Double-click startup scripts (recommended for beginners)

- **Windows:** Double-click `Start App.bat` in your project folder (in File Explorer,
  not inside VS Code).
- **macOS:** Double-click `Start App (Mac).command`. The first time, macOS may block it
  - see [Troubleshooting](#15-troubleshooting) below for how to allow it.

These scripts automatically create the virtual environment (if missing), install
dependencies, check your `.env` file, and launch the app.

### Option B - Manual command (from the VS Code terminal, with `venv` activated)

```
uvicorn main:app --reload
```

### Opening the app

Once running, you'll see log output ending in something like:

```
Uvicorn running on http://0.0.0.0:8000
```

Open your web browser and go to:

- **http://127.0.0.1:8000** - the main web app
- **http://127.0.0.1:8000/docs** - interactive API documentation (Swagger UI)

To stop the server, click back into the terminal window and press `Ctrl + C`.

## 14. Using Every Feature

### Uploading a PDF

1. Go to **http://127.0.0.1:8000/upload** (or click "Upload" in the app's navigation).
2. Drag and drop a PDF file onto the upload area, or click to browse for one.
3. Wait for the status to change from "Processing…" to "Ready". This means the PDF's
   text was extracted, split into chunks, and embedded into the vector search index.

### Chatting with your documents

1. Go to **http://127.0.0.1:8000/chat**.
2. Choose whether to search **all uploaded documents** or scope your chat to **one
   specific document** using the dropdown/selector.
3. Type a question about the content of your PDF(s) and press Enter or click Send.
4. The AI's answer will stream in token-by-token, followed by clickable **source
   citations** showing which document and page the answer was based on.

### Managing conversations

- Click **"New Chat"** to start a fresh conversation.
- Previous conversations are listed in the sidebar and are saved permanently (in the
  local SQLite database) - you can revisit them any time.
- Delete a conversation using its delete/trash icon in the sidebar.

### Managing documents

- View all uploaded documents and their status (ready/processing/failed) from the
  document list.
- Delete a document to remove both the file and its data from the search index.
- Generate an AI **structured summary** of a document (title, overview, key points,
  document type, estimated reading time) via the summary feature.

### Exploring the API directly

Visit **http://127.0.0.1:8000/docs** to see every API endpoint, try requests directly
in your browser, and view exact request/response formats - useful if you want to build
your own frontend or integrate this backend elsewhere.

## 15. Troubleshooting

**"python is not recognized as an internal or external command" (Windows)**
-> Python wasn't added to PATH during install. Reinstall Python and make sure to check
"Add python.exe to PATH" (see Section 2).

**"command not found: python3" (macOS)**
-> Python isn't installed, or Terminal needs to be restarted. Reinstall following
Section 2, then close and reopen Terminal.

**`ModuleNotFoundError: No module named 'fastapi'` (or similar)**
-> Your virtual environment isn't activated, or dependencies weren't installed. Re-run
Section 8 (activate) then Section 9 (install).

**The app starts but chat/upload requests fail with an OpenAI error**
-> Check that `OPENAI_API_KEY` in your `.env` file is correct, starts with `sk-`, has no
extra quotes or spaces, and that your OpenAI account has available credit
(https://platform.openai.com/usage).

**"Address already in use" / port 8000 is busy**
-> Another program (or a previous run of this app) is already using port 8000. Close
that program, or run `uvicorn main:app --reload --port 8001` and open
`http://127.0.0.1:8001` instead.

**macOS blocks `Start App (Mac).command` with "cannot be opened because it is from an
unidentified developer"**
-> Right-click (or Control-click) the file, choose **Open**, then click **Open** again
in the confirmation dialog. You only need to do this once.

**PowerShell won't let me activate the virtual environment**
-> Run `Set-ExecutionPolicy -Scope CurrentUser RemoteSigned` once in PowerShell, then
retry `venv\Scripts\Activate.ps1`.

**Uploading a PDF gets stuck on "Processing…" or shows "Failed"**
-> The PDF may be a scanned image with no selectable/extractable text (i.e. no OCR text
layer), password-protected, or corrupted. Try opening it in a PDF reader first to
confirm you can select/copy text from it.

**Nothing happens when I double-click the `.bat` file, or it flashes and closes**
-> Run it from a terminal instead so you can read the error: open Command Prompt,
`cd` into the project folder, then type `"Start App.bat"` and press Enter.

## 16. FAQ

**Do I need to pay for anything?**
Python, Git, VS Code, and this app itself are all free. OpenAI charges a small
per-request fee for generating answers and embeddings - see Section 11.

**Is my data private?**
Your PDFs and chat history are stored locally in the `data/` folder on your own
computer. Only the text needed to answer a question is sent to OpenAI's API when you
ask a question or upload a document (for embedding).

**Can I use a different AI provider instead of OpenAI?**
Not without code changes - the app is built specifically around the OpenAI API and
LangChain's OpenAI integrations (`langchain-openai`). This would require modifying
`services/embedding_service.py` and `services/rag_service.py`.

**Do I need to activate the virtual environment every time?**
Yes, once per terminal session - unless you use the `Start App` scripts, which handle
it automatically.

**Where is my data stored?**

- Uploaded PDFs: `data/uploads/`
- Search index: `data/vector_store/`
- Chat history & document metadata: `data/pdf_chat.db` (a SQLite database file)

**How do I stop the app?**
Click into the terminal window running it and press `Ctrl + C`.

**How do I completely reset the app (delete all documents and chats)?**
Stop the app, then delete the contents of `data/uploads/`, `data/vector_store/`, and the
`data/pdf_chat.db` file. Restart the app - it will recreate empty versions of these
automatically.

## 17. Common Mistakes

- ❌ Forgetting to activate the virtual environment before running `pip install` or
  `uvicorn` - you'll get "module not found" errors.
- ❌ Renaming `.env.example` incorrectly (e.g. to `env.example` or `.env.txt` instead of
  exactly `.env`) - the app won't find your settings.
- ❌ Leaving quotes around your API key in `.env`, e.g. `OPENAI_API_KEY="sk-..."` - use
  no quotes: `OPENAI_API_KEY=sk-...`
- ❌ Committing your real `.env` file to Git/GitHub - never share this file; it's already
  excluded via `.gitignore` for this reason.
- ❌ Uploading non-PDF files - only `.pdf` files are supported.
- ❌ Expecting the app to work with zero OpenAI account credit - check your usage/billing
  page if requests fail.

## 18. Security Recommendations

- **Never share your `.env` file or your OpenAI API key** with anyone or commit it to a
  public repository. If you ever accidentally expose a key, revoke it immediately at
  https://platform.openai.com/api-keys and create a new one.
- This app currently has **no login/authentication** - anyone who can reach the address
  it's running on can upload files and use your OpenAI credits. Keep it running only on
  your local machine (`127.0.0.1`) unless you've added your own authentication layer.
- Set a spending limit on your OpenAI account to avoid surprise charges.
- Keep the default `ALLOWED_ORIGINS=["*"]` setting only for local development - don't
  deploy the app publicly with this wildcard setting still in place.

## 19. Next Learning Steps

Once you're comfortable running and using this app, here's a suggested path to
understanding it more deeply:

1. **Read `README.md` and `docs/ARCHITECTURE.md`** in this project - they explain the
   concepts (RAG, embeddings, chunking, vector stores) and how the pieces fit together.
2. **Learn Python basics** - freeCodeCamp's Python course or the official Python
   tutorial (https://docs.python.org/3/tutorial/).
3. **Learn FastAPI** - the official docs (https://fastapi.tiangolo.com/) are
   beginner-friendly and directly relevant to this project's `routers/` and `main.py`.
4. **Learn Git basics** - being able to `git init`, `git add`, `git commit`, and push to
   GitHub will let you save versions of your work and share it. Try GitHub's own guide:
   https://docs.github.com/en/get-started.
5. **Learn about LangChain and RAG** - LangChain's own documentation
   (https://python.langchain.com/) covers the exact patterns used in
   `services/rag_service.py`.
6. **Try modifying the app** - small experiments (changing the chunk size in `.env`,
   tweaking the prompt in `services/prompt_templates.py`) are a great way to learn by
   doing, in your own local copy.

Good luck, and enjoy exploring the project! 🎉
